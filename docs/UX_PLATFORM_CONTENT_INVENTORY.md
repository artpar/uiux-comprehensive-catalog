## Work tools

- UX critique and problem statement (`ux-critique`): A concise critique with observations, hypotheses, user impact, and the next evidence to gather.
- Research and usability test plan (`test-plan`): A shareable plan with decision, participants, realistic tasks, observations, and limits.
- Design decision memo and state model (`decision-memo`): A memo covering alternatives, key states, authority, uncertainty, and a revision trigger.
