# Backlink Outreach Packet

Primary asset: UX Pattern Selection Checklist
URL: https://uxpatternsguide.com/resources/ux-pattern-selection-checklist/

## Best-fit prospects

- Design-system teams that maintain contribution, review, or component-selection docs.
- UX educators writing about interaction design, accessibility reviews, or product design critique.
- Frontend engineering blogs covering UI implementation requirements, component states, or AI-generated UI review.
- Product/design newsletters that share practical templates rather than broad inspiration.
- Open source UI libraries with docs pages about choosing components or avoiding misuse.

## Pitch angle

Most component guidance starts after a team has already named the component. This checklist helps teams decide whether the pattern fits the user's task, risk level, state requirements, accessibility contract, and evidence trail before the design reaches implementation.
